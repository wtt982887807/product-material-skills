# 产品要素审阅与物料更新

可安装的 Codex Skill 与本地 CLI。合同决定目标产品和内容；其他上传文件提供模板格式，可以来自不同产品。先广泛提取合同，再从模板发现逐项需求，回查合同补提，最后按依据生成并验收 Word/PPT。

## 一句话安装

把下面这句话发给另一台电脑上的 Codex：

> 从 https://github.com/wtt982887807/product-material-skills 的 skills/product-material-review 目录安装这个 Skill，一并安装 requirements.txt 中的依赖，然后运行 scripts/material_agent.py doctor 验证。

也可以直接提供 [Skill 目录链接](https://github.com/wtt982887807/product-material-skills/tree/main/skills/product-material-review) 并要求安装和环境检查。安装后使用 `$product-material-review`；不需要发送ZIP或编写JSON。

## 使用

> 使用 $product-material-review。合同是要制作的产品，其他文件只是格式模板，可以不同产品。内容按合同，格式按模板；Word先接受模板已有全部修订，再记录本次修订及批注，PPT只输出所选模板主体的产品要素页。缺项请列出并用明确占位代替旧产品内容。

- 输入：合同必需；PPT、一页通、海报至少一份。合同支持DOCX、可提取文字的PDF，旧DOC需可信转换副本和双哈希登记；自动回写支持DOCX/PPTX。
- 合同：保留原文、定位、适用条件、候选值及覆盖检查。通用候选不代表全部内容已结构化或核验。
- 模板：默认 `template` 模式。模板原产品与合同不同不报身份冲突。先识别模板自身主体，再映射为合同目标产品；信托模板的底层产品表继续排除，不能因为其与合同同名或标题写着“目标产品”就误选。范围不清时由AI检查并记录模板选择依据。
- 内容：选定范围的值、标题和页眉页脚逐项处置；按合同改写、经依据确认保留、缺项占位或有依据删除不适用内容。旧费率、旧日期、旧产品代码等不能因格式相同而沿用。待补稿不等于完成稿。
- Word：`analyze` 在工作副本接受模板原有全部修订，再以清洁底稿生成本次真实修订和锚定批注。上传原件不变，原批注保留；原件与底稿分别记录哈希。合同不执行该预处理。PPT：保留页内对象和格式，`apply` 自动只输出目标产品要素页；范围待核时阻断交付，不返回完整PPT。
- 文件：最终文件在 `delivery/`。海报和一页通沿用上传模板文件名；普通PPT在模板名后加“产品要素”。完整内部稿在 `internal/`，不作为最终文件。PPTX海报按海报命名。
- 核对：一格可以包含多项需求，例如管理费、托管费、计提和支付方式各自核实。字典不是白名单；新字段可先在本任务定义，回查全文、附件和上下文后引用合同原文补入底稿。
- 依据：合同补提与用户补充分开保存；补提引用绑定真实原文块及合同版本。先判断目标产品是否适用，再判断是否需要外部日期或其他参数。未查到不等于不适用。
- 验收：每项需求连接依据及最终正文；仅补充一条事实却没有改正文、漏核复合字段或沿用旧模板值，都不能宣布完成。未解决项保留明确待补状态。

## 运行要求

Python 3.11+，依赖为`lxml`和`pypdf`。CLI核心本地运行，不需要模型API密钥；语义审阅由当前AI会话执行。含历史修订的Word模板需要Windows及Microsoft Word来接受全部修订，普通无修订文件不需要该预处理。最后的原生打开与视觉验收需要Office或等效渲染器。扫描件、图片海报、复杂对象和未识别条款可能需要额外处理。

详情：[安装与迁移](skills/product-material-review/INSTALL.md) · [CLI](skills/product-material-review/references/cli.md) · [审阅依据](skills/product-material-review/references/review.md)。

## 版本与更新

当前公开包1.2.2，核心2.3.2。本次修复默认PPT选页交付与模板命名，增加Word模板先接受原有全部修订再生成本次修订，并要求对最终文件单独进行原生打开和视觉验收。默认合同内容＋跨产品模板；原同产品核对可显式使用 `--material-mode review`。支持 `search-contract` 回查及 `inspect-review` 核对报告。AI负责语义判断，CLI校验原文来源、需求覆盖和最终文字关联；不能据此保证机器自动发现所有信息。公开包不含业务原件、本机路径或历史审阅结论。

字段字典位于技能`runtime/config`，逐物料需求每次分析重新生成。更新代码或配置后旧审阅会失效；迁移文件到另一台电脑后重新分析，不能改旧task的路径或哈希冒充迁移。更新已安装版本时保留并复核自己的配置。

已安装电脑不会因为 GitHub 更新而自动同步。可发送：

> 请将我已安装的 product-material-review 更新为 wtt982887807/product-material-skills 中的最新版本；先备份现有版本、保留并检查我的自定义配置，更新完整 Skill 目录和依赖，运行 doctor，并报告安装版本。

## 验证范围

回归范围包括跨产品模板选择、信托主体与底层隔离、新字段合同补提、复合需求覆盖、原文引用验证、待补及不适用判断、Word修订批注和PPT选页。发布时验证独立目录安装、文件完整性、doctor和跨产品模板分析。具体合同仍需语义审阅与原生/视觉验收；未完成字段和复杂对象会保留待处理状态。
